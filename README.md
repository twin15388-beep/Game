# EMBERFALL — Пепел Вечности (v10: рельеф, горы, деревни, лагеря, расширенный мир)

Тёмно-фэнтезийный открытый мир в духе **Deepwoken / Arcane Odyssey / World of Magic / Clover RPG**.
Один файл `.rbxlx` — открыл в Studio, нажал **F5**, играешь.

---

## Как открыть (2 минуты)

1. Скачай **`Emberfall_Map_v10.rbxlx`** из корня репозитория (или `release/Emberfall_v10.zip`).
2. Roblox Studio → **File → Open from File…** → выбери `Emberfall_Map_v10.rbxlx`.
3. Нажми **F5** (Play). Ты появишься на площади Пепельной Пристани.
4. У спавна табличка «EMBERFALL v10». Если написано v8 или v7 — открыт старый файл.

> Первый запуск: Studio может 5–10 секунд прогружать 18 000 объектов. Это нормально.

## 🎮 Управление
| Клавиша | Действие |
|---|---|
| **ЛКМ** | Удар оружием (ближний бой) |
| **1–6** | Заклинания из хотбара |
| **Shift** | Спринт (тратит выносливость) |
| **E** | Говорить с NPC / открыть сундук (подсказка появляется сама) |
| **C** | Персонаж: статы, экипировка. Ещё раз **C** — окно магии |
| **J** | Журнал заданий |
| **I** или **Tab** | Рюкзак |
| **Esc** | Закрыть все окна |

### 🔥 Магия — 5 стихий по 4 заклинания
Огонь, Лёд, Молния, Тень, Природа. У каждой:
- базовый снаряд (1 уровень),
- урон/контроль/бафф среднего уровня,
- ультимативное заклинание (метеор, гроза, цепь молний…).

**Как получить магию:** коснись **АЛТАРЯ СТИХИЙ** (светящийся кристалл справа от спавна, ~58,138)
→ выбери стихию (навсегда) → базовое заклинание сразу в хотбаре.
Новые заклинания открываются по уровню автоматически, а изучить остальные можно в окне **C → магия**.

### ⚔ Мобы и боссы
- **~53 точки спавна** по 8 зонам. Мобы спавнятся только рядом с игроком (200–260 студов), далёкие убираются — не лагает.
- 22 вида: теневые волки, гоблины, разбойники, утопленники, призраки корсаров, морозные волки,
  снежные големы, болотные гады, зомби, грибные шаманы, пепельные псы, мародёры, лавовые элементали,
  скелеты, скелеты-лучные, культисты, костяные стражи, теневые стражи, кристальные големы…
- **Элитные** (оранжевая полоска) — в 2–4 раза толще и больнее.
- Мобы ходят по земле (рейкаст), преследуют, бьют вблизи; часть — **стреляет снарядами**.
- **6 боссов** на аренах: Ледяной Призрак, Ледяной Колосс, Мать Болот, Склепный Призрак,
  Пепельный Владыка, Безымянный Король. У боссов **3–4 фазы**, способности
  (сокрушающий удар, залп, ледяная новая, ядовитая волна, метеоритный дождь, зов слуг),
  полоса HP сверху экрана и респавн 2,5–5 минут.

### 📈 Прокачка
- Опыт за мобов/боссов/квесты, уровни до 60, **3 очка характеристик** за уровень.
- Характеристики: Сила, Живучесть, Прозрение, Ловкость, Защита — влияют на урон, HP, ману, скорость, броню.
- Смерть: потеря 5% опыта текущего уровня, респавн через 5 секунд.

### 📜 Квесты — 22 задания, цепочки, награды
- У NPC над головой **золотой «!»**, если есть что предложить или сдать.
- Квесты: убить N мобов, убить в зоне, принести материалы, победить босса, выбрать стихию.
- Цепочка ведёт от Пристани → Глумвуд → Морозные Пики → Пустоши → Костяные Поля → Бездна.
- Финал: **Безымянный Король** (60 уровень, 16 000 HP) и легендарные Клинок Бездны / Саван Бездны.

### 🎒 Предметы, лут, магазины
- 30+ предметов: оружие, броня, амулеты, зелья, материалы. 5 редкостей (белый → зелёный → синий → фиолетовый → золотой).
- Лут падает с мобов и боссов, **13 сундуков** по карте (откат 4 минуты на игрока).
- Торговец и кузнец: покупка/продажа. Лекарь лечит за 40 монет.
- Экипировка меняет реальные характеристики (урон, броня, мана, скорость).

### 🖥 Интерфейс
- Полосы HP/маны/выносливости/опыта, уровень, монеты, название зоны.
- Хотбар с откатами и стоимостью маны, цифры урона (криты золотым, лечение зелёным).
- Всплывающие уведомления, полоса босса, экран смерти, окна персонажа/магии/заданий/рюкзака, диалоги NPC.

## Что проверить в первую очередь (тест-лист)

1. **Магия**: коснись алтаря → выбери Огонь → нажми **1** → в моба летит искра, цифры урона видны.
2. **Ближний бой**: подойди к волку в Глумвуде, клик **ЛКМ** — моб теряет HP, полоска над головой падает.
3. **Мобы держат землю**: убей волка — он не проваливается и не висит в воздухе.
4. **Квесты**: поговори с Хранителем Знаний (**E**), возьми «Первые шаги», убей 5 мобов,
   открой **J** → «СДАТЬ» → пришли монеты и опыт.
5. **Босс**: `!мороз` в чате → иди к арене → сверху появится полоса «Ледяной Колосс»,
   после 60% HP он ускорится и начнёт призывать слуг.
6. **Рюкзак/экипировка**: **I** → клик по мечу → «надето», урон вырос (видно в **C**).
7. **Сундук**: подойди к сундуку (например `!крипта`), нажми **E** — лут в уведомлениях.

## Известные ограничения (честно)

- **Прогресс не сохраняется** между сессиями (нет DataStore — следующий шаг).
- Мир стал тяжелее: ~41 000 объектов, файл ~34 МБ. Studio открывает 10–20 секунд.
- Мобы/боссы — процедурные модели из частей, без анимаций (покачивание при ходьбе есть).
- Голосовых звуков нет, только визуальные эффекты.
- PvP между игроками отключён (дружелюбный огонь тоже).
- Дальние мобы не думают, пока игрок не подойдёт ближе 260 студов — это сделано намеренно для FPS.
