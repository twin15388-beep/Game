# HANDOFF: Emberfall — Пепел Вечности (v8: геймплей)

Документ для следующего ИИ/разработчика. Читать целиком перед правками.

## 0. TL;DR

Карта готова (v7 → 18 374 объекта). В **v8** добавлен весь геймплей:
магия, мобы, боссы с фазами, прокачка, квесты, лут, магазины, интерфейс.
Код разложен по файлам `src/lua/**`, из них генерируется `gen_lua.py`,
который `gen_map.py` вшивает в `.rbxlx`. Одна команда: `python3 build.py`.

---

## 1. Формат работы (важно!)

Пользователь — русскоязычный новичок в Roblox Studio. Схема:
**ИИ делает целиком → пользователь открывает .rbxlx в Studio, тестирует,
говорит «нюансы» (скриншоты/ошибки) → ИИ правит и перевыпускает файл.**

Правила:
- Отвечать по-русски, коротко и по делу.
- Всегда собирать новый **файл** (не инструкции «как поправить в Studio»),
  пользователь сам код не правит.
- Каждая версия: табличка у спавна «EMBERFALL vN» + имя файла с версией,
  плюс `release/Emberfall_vN.zip` — иначе пользователь путается, какой файл открыл.
- Если пользователь присылает скриншот с проблемой — сначала воспроизвести
  проблему в коде, потом править, потом написать «что именно изменилось».

## 3. КРИТИЧЕСКИЕ ТЕХНИЧЕСКИЕ УРОКИ (не повторять!)

### 3.1 rbxlx
1. **token = ЦЕЛОЕ ЧИСЛО, не имя.** Material: Plastic=256, SmoothPlastic=272,
   Neon=288, Wood=512, WoodPlanks=528, Marble=784, Basalt=788, Slate=800,
   Concrete=816, Granite=832, Brick=848, Cobblestone=880, Rock=896, Sandstone=912,
   Metal=1088, Grass=1280, Fabric=1288, Sand=1296, Snow=1328, Mud=1344,
   Ground=1360, Ice=1536, Glacier=1552, CrackedLava=1560, Water=2048.
   Shape: Ball=0, Block=1, Cylinder=2. Surface Smooth=0.
   Если написать имя — Studio молча отбросит свойство (мир «из точек»).
2. **Lua в rbxlx — только через `<ProtectedString name="Source">`** с XML-экранированием.
   Иначе `&&`, `<`, `>` в коде ломают парсинг.
3. Скрипты не должны быть в `Workspace` — только `ServerScriptService`
   (и `ReplicatedStorage` для модулей, `StarterPlayerScripts` для клиента).
4. `StreamingEnabled = false` — иначе часть мира исчезает.

### 3.2 Lua / Luau
5. **`until` — зарезервированное слово.** Имя поля `until` в таблице — синтаксическая
   ошибка (`attempt to assign to const variable`). В баффах используется `expires`.
6. `unpack` в Luau заменён на `table.unpack`.
7. Для клиент-серверных сообщений объекты `Instance` передаются по ссылке —
   удобно: клиент шлёт саму часть сундука, сервер ищет по позиции.
8. `wait()` устарел — только `task.wait/delay/spawn`.
9. `Player.RespawnTime` — это свойство `Players`, а не `Player`.

### 3.3 Архитектурные грабли, которые уже поймали
10. **Все мобы/боссы бьют только через `Combat.damageMob` / `Combat.damagePlayer`.**
    Иначе не работают лут, опыт, квесты, цифры урона.
11. **Замедление моба — через `mob.speedMult`**, а не мутацией `mob.def.speed`
    (def общий для всех мобов вида → замедление расползалось на всех).
12. **Маркеры (`MobSpawn_*`, `BossSpawn_*`, `ArenaTrigger_*`, `NPC_*`, `ZoneTrigger_*`,
    `Chest_Body_*`) разложены по папкам биомов** внутри `Workspace.World`,
    а НЕ в `GameLogic` (там только `ZoneTriggers`). Поэтому все сервисы ищут
    через `Workspace:GetDescendants()` + `Name:match("^...")`. Не меняйте на
    `FindFirstChild("MobSpawns")` — точки спавна пропадут.
13. **Рейкаст земли** (`MobService.groundY`) фильтрует `GameLogic`, `EmberfallFx`,
    `EmberfallWorld`, папку мобов. Иначе мобы встают на невидимые маркеры/триггеры.
14. **Оружие-модели (weld) `CanQuery=false`** у всех мелких частей мобов — иначе
    снаряды врезаются в собственные модели и луч земли не проходит.
15. Скорость персонажа клиент читает из `Humanoid:GetAttribute("EmberSpeed")`
    (сервер пишет её в `PlayerState.recompute`), поэтому спринт не «залипает».
16. Клавиши: `Enum.KeyCode.One` (не `"1"`), цифры — таблица `NUMBER_KEYS` в `SpellBar`.
17. Клик ЛКМ не должен бить, если курсор над UI: `UserInputService:GetGuiObjectsAtPosition`.

## 4. Что где в коде

### Сервер
| Модуль | Ответственность |
|---|---|
| `PlayerState` | уровень/опыт/статы, инвентарь (uid-предметы, стопки), экипировка, производные характеристики (`recompute`), отправка состояния клиенту |
| `Combat` | единая точка урона/смерти, лут, опыт, хуки `onMobKilled/onBossKilled/onPlayerDied`, цифры урона |
| `MobService` | модели мобов из частей (4 типа: humanoid/beast/golem/floating), ИИ (агр, погоня, ближний бой, дальний бой), спавн по маркерам с LOD, респавн |
| `BossService` | арены по `ArenaTrigger_*`/`BossSpawn_*`, фазы по % HP, 6 способностей, полоса HP, респавн, слуги |
| `MagicService` | каст: проверка маны/уровня/отката, projectile/area/meteor/dash/buff/heal/storm/chain |
| `QuestService` | приём/прогресс/сдача квестов, цели kill/killZone/boss/collect/visit/flag |
| `WorldService` | NPC на `NPC_*` (модели + табличка + «!»), сундуки, зоны по `ZoneTrigger_*`, алтарь стихий, лава |
| `InteractService` | ProximityPrompt (E) на NPC/сундуках/алтаре |
| `Main` | Remotes, связывание сервисов, все обработчики запросов, регенерация, спавн-кит |

### Клиент
| Модуль | Ответственность |
|---|---|
| `HUD` | полосы, уровень, монеты, зона, уведомления, цифры урона (BillboardGui), полоса босса, экран смерти, подсказки |
| `SpellBar` | 6 слотов, откаты, стоимость маны, клавиши 1–6, клик |
| `Panels` | окна: персонаж (C), магия (C×2), задания (J), рюкзак (I/Tab), диалог NPC, магазин, выбор стихии |
| `Fx` | визуал: взрывы, нова, молнии, цепь, метеор-предупреждение, взмах |
| `Controls` | ЛКМ-удар с анимацией руки, спринт на Shift + выносливость, проверка курсора над UI |
| `UIKit` | фабрика Frame/Label/Button/Bar/градиенты (строим UI кодом, без .rbxmx) |

### Порядок запуска
- Сервер: `EmberfallMain` (Script) → `require` девяти ModuleScript из `EmberfallServer`.
  `Main` — единственный, кто делает `require` сервисов; остальные — обычные возвращаемые таблицы.
- Клиент: `EmberfallClient` (LocalScript) → `require` модулей из `StarterPlayerScripts`.

## 5. Данные и баланс

- **Config** (`src/lua/shared/Config.lua`) — все числа: HP/мана/урон/скорость/реген,
  опыт по уровням (`40 * level^1.52 + 45*level`), цены, кулдауны, стихии (цвета/иконки).
- **GameData** — 22 моба, 6 боссов, 30 предметов, 20 заклинаний, ассортимент лавки.
- **Quests** — 22 задания с предпосылками (`prereq`), цепочки: Пристань → Глумвуд →
  Пики → Пустоши → Костяные Поля → Бездна.
- **NPCData** — 10 NPC: кто, где, что говорит, роль (quests/shop/heal).

Балансные ориентиры (менять осторожно):
- Урон игрока: `(урон оружия) * (1 + 0.04 * Сила) * (1.6 при крите)`.
- Защита: `итог = урон * 100 / (100 + броня)`.
- Если разница уровней моба и игрока > 8 — входящий урон режется до 45%.

## 6. История версий

- v1–v7: карта (8 биомов 6000×6000, цитадель, парящий архипелаг, порт, данжи, паркур,
  сундуки, погода, плавание, 30+ телепортов в чате). Подробности — в старом README.
- **v8 (эта):** весь геймплей — магия 5 стихий × 4 заклинания, 22 моба с ИИ,
  6 боссов с фазами, прокачка до 60, 22 квеста, лут, магазины, HUD, окна, алтарь стихий,
  ProximityPrompt-взаимодействия, спринт, смерть/респавн.

## 7. Дорожная карта

- **v9 — сохранение:** DataStore (уровень, статы, инвентарь, квесты), автосейв 60с,
  защита от потери при выходе (`game:BindToClose`), лидерборд.
- **v10 — анимации и звуки:** замена процедурных мобов на риг-модели с анимациями,
  удары/касты/смерть, звуки заклинаний по стихиям.
- **v11 — подземелья и мир:** инстанс-данжи (крипта/гробница/Бездна), ежедневные боссы,
  мировые события, рыбалка, лодки.
- **v12 — социальное:** группы, PvP-арены, рейтинг, торговля между игроками.
